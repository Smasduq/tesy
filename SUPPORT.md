# Support

## Getting help

- Read the [README](README.md) first - it covers providers, voice setup, file
  tools, and every command-line flag.
- Search [existing issues](https://github.com/Smasduq/tesy/issues) before
  opening a new one.
- For bugs, open an issue with the bug report template. Include your Python
  version, operating system, the command you ran, and the full error.
- For feature ideas, open an issue with the feature request template.

## Security

Do not report vulnerabilities in public issues. Follow
[SECURITY.md](SECURITY.md).

## Not supported

- Recovering deleted files or undoing changes Tesy made. Tesy cannot write,
  move, or delete files.
- Problems with an upstream provider, model, Ollama, whisper.cpp, piper, or
  PipeWire. Report those to the relevant project.
- Requests for help with credentials you do not own.

## Response expectations

This is a small project maintained in spare time. Issues and pull requests are
read as time allows; there is no guaranteed response time.
